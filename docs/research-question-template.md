# Bounded research question template

Copy and fill this template for a proposed experiment. Empty fields are open
questions, not permission to infer inputs. Read the
[research foundation](research-foundation.md) first. This template introduces no
new model, acquisition permission or clinical claim.

- What this experiment cannot conclude:
- Owner/reviewer and status (proposed, running, completed, unresolved):

- Derivation of any parameter from a reported quantity, with a separate justification:
- Rights/permission boundary for any future acquisition or execution:
